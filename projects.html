[ EXPERIMENT LAB ]

Decisions that changed the result.

// one per project · each links to its decision log
01 · multimodal

IssueFine-tuning all of MedCLIP overfit almost at once. Validation loss climbed after the first epochs — a few hundred patients can’t re-teach a foundation model.

→

DecisionKept the pretrained encoder frozen and trained only the heads.

ResultStable training and better generalisation.

 02 · ultrasound

IssueThe baseline missed too many cancers. It caught only 55% of malignant cases — not acceptable for screening.

→

DecisionUsed EfficientNet-B0 transfer learning on the same balanced data.

Result98% malignant recall and 95.75% accuracy.

 03 · aura

IssueIt once published junk while every run showed green. An earlier version silently fell back to keyword heuristics and, for days, published sports and celebrity stories as corporate intelligence.

→

DecisionFail loudly: if every provider fails, the run exits non-zero and publishes nothing. Every record now stores which model produced it.

ResultNo more quiet bad data; failures are visible.

 04 · polling

IssueThe source data was mislabelled. Some “LGA” columns actually contained State names.

→

DecisionAdded a semantic mapping layer that corrects these during extraction.

ResultA consistent hierarchy instead of hand-fixing every sheet.
