01 / 04 · medical imaging · final-year project

Multimodal breast cancer detection.

Looks at a breast scan and the patient’s clinical record together, and suggests one of three diagnoses.

Image features from MedCLIP and clinical features from TabNet are combined in a late-fusion model, then served through a FastAPI backend in Docker with API contract tests.

02 / 04 · medical imaging · benchmark

Breast ultrasound classification.

Sorts breast-ultrasound images into diagnostic classes. The deep model beat a classic baseline by more than 37 percentage points.

EfficientNet-B0 transfer learning against Random Forest + PCA on the public BUSI dataset, with classes balanced by augmenting to 4,000 images each.

EfficientNet-B0 (deep model)95.75%
Random Forest + PCA (baseline)58.2%
0.99 AUC-ROCClasses balanced to 4,000 images each before training.

03 / 04 · llm systems · automation

AURA news intelligence system.

Reads the news, writes short summaries and scores the sentiment of each story, on its own, four times a day.

An LLM cascade runs on GitHub Actions, stores results in Google Sheets and publishes a live dashboard on GitHub Pages, at zero hosting cost.

04 / 04 · data engineering · internship

Nigeria polling unit data pipeline.

Replaced manual copying of polling-unit records with a scraper that produces one clean, structured workbook.

Selenium walks Nigeria’s State → LGA → Ward → Polling Unit hierarchy, a mapping layer fixes mislabelled columns, and tests run on GitHub Actions.
