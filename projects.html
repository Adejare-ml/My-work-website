[ FEATURED CASE ]

Multimodal Breast Cancer Detection.

// final-year project · 2025
// the problem

An image alone misses context a clinician has on paper. The project combines MedCLIP image embeddings with TabNet clinical features to give a three-class diagnosis — on a small, imbalanced, real dataset.

pytorch · medclip · tabnet · fastapi · docker
// the result 
img (medclip) ─▶ p_img ──┐
                         ├─▶ late fusion ─▶ dx (3 classes)
tab (tabnet)  ─▶ p_tab ──┘

Served through a FastAPI backend, Dockerised, with API contract tests.

[ THE HONEST SECTION ]

Engineering Decisions & What Didn't Work.

// two dead ends, kept deliberately public — expand any entry

A few hundred patients cannot re-teach a foundation model. Unfreezing the full encoder memorized the training set while validation collapsed — the fix was accepting the pretrained features as-is.

→ shipped: frozen encoder; only the image classifier head and tabnet train

Early runs looked great until the confusion matrix told the truth. Model selection moved to ROC-AUC, training got a class-weighted loss, and every later comparison reports both.

→ shipped: weighted loss + auc-based model selection
