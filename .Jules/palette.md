## 2026-09-24 - Make Command Palette Discoverable\n**Learning:** Keyboard-only features like a command palette (Ctrl+K) can be completely missed by users if there isn't a visible trigger in the UI, rendering a powerful tool inaccessible and undiscoverable to most users.\n**Action:** Add a visible, accessible trigger (e.g., a '⌘K' link in the main navigation) connected to the same event handler to ensure all users can discover and use hidden shortcut features.
