
## 2026-10-05 - Enhance Command Palette Accessibility and Keyboard Navigation
**Learning:** For custom listbox widgets without native `select` implementations, pairing `aria-activedescendant` on the combobox with programmatic scroll control (`scrollIntoView({ block: 'nearest' })`) on the active element provides optimal accessibility. Screen readers rely on the `aria-activedescendant` attribute to identify the currently active descendant without shifting actual focus away from the input, while scrolling ensures the visual interface syncs perfectly with keyboard navigation (up/down). Setting it properly also involves tying `role="combobox"`, `aria-expanded`, and `aria-controls` explicitly together.
**Action:** When building or fixing custom combobox list widgets, ensure option items have unique IDs for `aria-activedescendant`, make the dropdown state explicit with `aria-expanded` and `aria-controls`, and manually call `.scrollIntoView({ block: 'nearest' })` on the selected list node during keyboard interaction to keep it in view for sighted keyboard users.
