// medical imaging · benchmark

Breast ultrasound classification

Sorts breast-ultrasound images into diagnostic classes. The deep model beat a classic baseline by more than 37 percentage points.

EfficientNet-B0 transfer learning against Random Forest + PCA on the public BUSI dataset, with classes balanced by augmenting to 4,000 images each.

EfficientNet-B0 (deep model)95.75%
Random Forest + PCA (baseline)58.2%
0.99 AUC-ROCClasses balanced to 4,000 images each before training.

Experiment Lab.

// what didn’t work, and what I changed
EXP_LOG_01 // BREAST ULTRASOUNDDidn’t work: Random Forest + PCA

Classic ML on raw pixels stalled at 58.2%

TriedRandom Forest on PCA-reduced ultrasound images. It couldn’t pick up texture and shape in the scans.

→

Changed toEfficientNet-B0 transfer learning on the same balanced data reached 95.75%.

EXP_LOG_02 // FOUNDATION MODELSDidn’t work: full fine-tune

Unfreezing all of MedCLIP overfit almost at once

TriedFine-tuning the whole encoder on a small medical dataset. Validation loss climbed after the first epochs.

→

Changed toKept the pretrained encoder frozen and trained only the heads.

EXP_LOG_03 // METRICSShipped: weighted loss + ROC-AUC

Accuracy hid a useless model

TriedJudging early, imbalanced models by accuracy. A model that called everything “benign” looked good.

→

Changed toWeighted the loss and picked models by ROC-AUC instead.
